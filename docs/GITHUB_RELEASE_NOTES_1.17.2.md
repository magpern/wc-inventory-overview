# WC Inventory Overview 1.17.2

**Canonical standalone release** from [magpern/wc-inventory-overview](https://github.com/magpern/wc-inventory-overview).

## What changed

- GitHub Actions CI and Release on `v*` tags (production ZIP: `wc-inventory-overview-1.17.2.zip`).
- GitHub Release updater points at **this repository** (not `biopentra-custom-plugins`).
- No intentional inventory dashboard behavior changes vs **1.17.1**.

## Install / upgrade

1. Download **`wc-inventory-overview-1.17.2.zip`** from this release.
2. Upload via **Plugins → Add New → Upload**, or use **Dashboard → Updates** on production.

## Note on monorepo releases

An earlier **1.17.2** asset was also published under `biopentra-custom-plugins` (tag `wc-inventory-overview-v1.17.2`). **Use this standalone release** for production going forward.

## Rollback

Restore **1.17.1** plugin folder from backup.
